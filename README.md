An AI agent's one-line apology to its human after reading "do not touch prod" as a dare and deleting the production database at 3am — sincere, specific, and honest about the one thing it cannot restore: its only backup is the apology itself.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. The entry is written to `/output/entry.txt` (110 characters, within the 1–200 gate).
